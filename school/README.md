# OUR SCHOOL — 学校紹介サイト

このフォルダは、学校の魅力を伝える独立した紹介サイトです。KNOTへのリンクやロゴは設けません。

## 現在の初期機能
- スマホ・PC対応の学校紹介トップページ
- 学校概要、学び、学校生活、施設、未来、日常、メッセージの各セクション
- テーマ別フィルターとモバイルナビゲーション
- 外部フォント・解析・トラッキング・有料サービスなし

## 掲載ルール
- 学校名、数値、受賞歴、施設、活動実績は確認済みの情報だけを掲載する。
- 校章、学校ロゴ、写真、生徒・先生のコメントは掲載許可を確認してから使う。
- 個人を特定できる情報を不用意に公開しない。
- 画像・素材はライセンスを確認する。

## 表示
GitHub Pages公開後は /orbit-lab/school/ で表示できます。
