# ORBIT

A lightweight, responsive personal workspace built with plain HTML, CSS and JavaScript.

## Features
- Focus timer with 15 / 25 / 50 minute presets
- Quick notes saved locally in the current browser
- Task checklist with completion tracking
- Calculator
- Rotating daily reminders
- School mode for a calm, school-appropriate presentation

## Privacy
Notes, tasks and mode preferences are stored in the browser's local storage. They are not sent to a server. Avoid entering sensitive personal information on a shared device.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## GitHub Pages
The included workflow deploys the static site to GitHub Pages when changes are pushed to `main`.
