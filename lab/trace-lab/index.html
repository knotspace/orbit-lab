HOW TO USE

TRACE LABの使い方

リンクを作る人・受け取る人、それぞれの操作を順番にまとめています。

リンクを作る人

  1. 「びっくり表示」か「URL転送」を選びます。
  2. URL転送の場合だけ、移動先のURLを入力します。example.com のように https:// を省略しても自動で補います。
  3. 「共有URLを発行する」を押すと、相手に送るURLと、記録を見るための制作者専用URLが表示されます。
  4. 共有URLを相手に送ります。相手が開くとアクセス情報が記録されます。
  5. 記録を確認するときは「アクセス記録を確認する」または制作者専用URLを開きます。専用URLは自分だけで保管し、他人に送らないでください。

リンクを受け取った人

  1. リンクを開くと、IPアドレス・IPから推定した地域・アクセス時刻などがリンク作成者に記録されます。
  2. びっくり表示では、自分のIP情報と推定地域が画面に表示されます。
  3. 任意のメッセージ・生年月日・性別を入力して送信できます。入力は任意です。
  4. GPS共有は任意です。共有ボタンを押し、ブラウザの許可をした場合だけ位置情報が送信されます。許可しなくても利用できます。
  5. URL転送モードでは、記録後に設定されたページへ移動します。

知っておきたいこと

  • IPから分かる地域はあくまで推定で、住所や正確な現在地ではありません。
  • GPSは本人が操作して許可しない限り取得しません。
  • 共有URL・制作者専用URLは発行から24時間で失効します。
  • アクセス情報は相手に分かる形で通知されます。相手の同意なく追跡・監視する目的では使わないでください。

IP情報について

IPアドレスは通信に使われる識別番号です。地域はネットワーク情報からの推定で、実際の現在地や住所を示すものではありません。GPSは訪問者が自分でボタンを押して許可した場合のみ共有されます。
